# ГЕЛИОСФЕРА: Космическая Одиссея

Интерактивный 3D-симулятор Солнечной системы на **Three.js + TypeScript + Vite**.
Живое Солнце, честные эфемериды на любую дату, разрезы недр, посадка на планеты,
научные лаборатории и исторические миссии — всё на русском языке, понятно ребёнку 10 лет.

## Запуск

```bash
npm install
npm run dev        # разработка → http://localhost:5173
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # предпросмотр production-сборки
```

## Архитектура (Master Spec v2.0)

### Ядро движка (`src/core`)

| Модуль | Что делает |
|---|---|
| `SpringMath` | Критически демпфированная пружина `settle(state, target, dt, seconds)` (4 подшага/кадр) и огибающая `burst(age, rise, fall)` для вспышек. Закон «Nothing Pops». |
| `SpaceManager` | Три семантических пространства: `SYSTEM_SPACE` (0.1 / 20000), `ORBIT_LOCAL_SPACE` (0.01 / 500, **Floating Origin**), `SURFACE_PATCH_SPACE` (0.1 / 50000). Плавающий центр координат и динамические `camera.near/far`. |
| `CameraRig` | Конечный автомат: `CINEMATIC_INTRO · SYSTEM · ORBIT · CUTAWAY · RING_DIVE · SURFACE_WALK · SPACECRAFT_FLIGHT`. Минимальная дистанция `radius * 1.02 + terrainHeight`. |
| `PostFX` | **Selective Bloom** через `THREE.Layers`: светятся только Солнце, корона, протуберанцы, огни, двигатели. ACES-тонмаппинг через `OutputPass`. |
| `QualityManager` | Профили `Low / Medium / High / Ultra`: DPR, bloom, звёзды, облака, камни террейна. |
| `AmbientAudio` | Процедурный «звук космоса» на WebAudio (дрон + ветер + «звёздные» всплески), без ассетов. |

### Рендер (`src/render`)

- **Sun** — GLSL-грануляция фотосферы, лимбовое потемнение, солнечные пятна, 3D-протуберанцы (`TubeGeometry`), трёхслойная корона, два режима: *видимый свет* и *УФ-фильтр SDO*.
- **Planet** — PBR-пайплайн (`MeshStandardMaterial` + процедурные `map / normalMap / roughnessMap / emissiveMap / displacementMap`), LOD **0–3** с гистерезисом, настоящая shadow map облаков от направленного солнечного света, отдельный selective-bloom слой ночных огней, полярные сияния.
- **Atmosphere** — рэлеевское рассеяние: френелевский ободок, закатное покраснение терминатора (у Марса — **голубой закат**!).
- **Rings** — щель Кассини и деление Энке, микроструктура, **честная тень планеты на кольцах** и тень колец на коре (GLSL-инъекция в шейдер планеты). `RingDiveField` — поле из тысяч 3D-глыб для режима «Нырнуть в кольца».
- **VortexField** — анимированные curl-noise потоки в атмосферах Юпитера, Сатурна, Урана и Нептуна: Большое Красное Пятно и полярный гексагон живут во времени, а не являются статическими наклейками.
- **Cutaway** — пружинный разрез недр: сектора-«корки» раздвигаются каскадом (`stagger 0.035s, stiffness 64, damping 14.2`), обнажая слои от коры до ядра с русскими 3D-выносками. Для Урана и Нептуна внутри мантии теперь идёт анимированный поток частиц **алмазного дождя**.
- **textures** — все PBR-текстуры синтезируются процедурно в `CanvasTexture` (шум fBm, кратеры, пояса гигантов, Большое Красное Пятно, гексагон Сатурна, «тигровые полосы» Энцелада).

### Данные (`src/data`)

- `bodies` — каталог 19 тел: физика, климат, атмосфера, факты для детей; два масштаба сцены: **музейный** ↔ **реальные пропорции**.
- `ephemeris` — **реальные гелиоцентрические координаты**: элементы JPL (Standish, 1800–2050) + лунная теория Шлителя. Расстояния и задержки света считаются для любой даты.

### Режимы (`src/modes`, `src/surface`) — 4 этапа спецификации

1. **Этап 1** — ядро, интро, Солнце, PBR-планеты, кольца, разрез недр, «Живая эфемерида» / «Машина времени».
2. **Этап 2** — посадка и прогулка (`SurfaceWorld`: террейн с кривизной горизонта, следы, бросок камня, пылевые дьяволы, метановое озеро Титана, модуль «Аполлон»), **управляемый марсоход** с бурением камней, **спуск на Венеру** сквозь облака с радаром и «блинчатыми куполами», «Сравни миры» с прыжком-тестом, «Спектральный сканер» (видимый / ИК / радар / магнитометр / сонар), «Нырнуть в кольца» с пастухами, погружение в облака Юпитера.
3. **Этап 3** — «Что если?» (4 эксперимента с реальными изменениями сцены: орбита Марса, вращение Земли, атмосфера, ядерный синтез Юпитера), «Скорость света и радиосвязь» с мини-игрой марсохода, «Опасности космоса» (буря, авроры, гейзеры, вулканы Ио), квест «Где искать жизнь?».
4. **Этап 4** — «Стань космонавтом» (тяга, гравитация, парашют, **тренажёр гравитационной пращи**), 6 исторических миссий с настоящими датами и **отдельными 3D-сценами маршрутов** (Аполлон-11, Voyager-1, Cassini, Perseverance, Parker, Europa Clipper), песочница «Построй свою систему» с симплектическим **N-тел интегратором**, «Фотолаборатория» (FOV, экспозиция, чистый кадр, PNG-снимок, **геометрическая модель затмения**).

## Подключение Google 3D Tiles (Земля, Луна, Марс)

В интерфейсе есть режим **🗺️ Google 3D-карты**. Он создаёт локальное ENU-пространство вокруг выбранной точки, подгружает glTF/b3dm по `root.json`, умеет `Meshopt`, LOD по screen-space error, кэш с LRU-очисткой и оставляет родительский тайл видимым, пока ребёнок не готов.

1. В Google Cloud включите **Map Tiles API**, создайте браузерный ключ и ограничьте его HTTP referrer-ами. Ключ является клиентским по природе Map Tiles API — не храните его в git.
2. Можно создать `.env` из `.env.example` и записать `VITE_GOOGLE_MAPS_API_KEY=...`, либо вставить ключ прямо в панель. Форма по умолчанию сохраняет его только в `localStorage` после явного флажка.
3. Для Земли оставьте URL пустым: используется официальный `https://tile.googleapis.com/v1/3dtiles/root.json?key=...`. Широта/долгота по умолчанию — Нью-Йорк; преобразование ECEF → локальный ENU убирает гигантские координаты.
4. Для Луны и Марса у Google Maps Photorealistic Tiles нет стандартного публичного `root.json` в этом API на момент реализации. В каркасе уже есть тот же адаптер `Google3DTilesProvider`: укажите URL совместимого Google/OGC 3D Tiles набора, выберите `Уже локальные` или `ECEF`, и ключ будет добавлен к запросам. Если набор использует `implicitTiling`, каркас разворачивает базовое QUADTREE по шаблону content и оставляет родителя при ответе 404; bitstream availability из `.subtree` можно подключить в том же адаптере без изменения UI.

Для production используйте отдельный ограниченный ключ и серверный прокси/преподписанные URL, если политика проекта не разрешает отдавать ключ браузеру.

## Управление

| Ввод | Действие |
|---|---|
| ЛКМ + перетаскивание | вращение камеры |
| Колесо | масштаб (приближение к планете включает Floating Origin) |
| ПКМ + перетаскивание | панорама |
| **Пробел** | разрез недр / прыжок на поверхности |
| G / E | бросить камень · бурение (марсоход и пешком) |
| 1–9 | быстрый выбор тела |
| R | сброс вида · M — звук |
| WASD / Shift / P | прогулка, ровер и полёт корабля |

## Технические принципы

- Никаких глобальных гигантских координат: только локальные пространства + Floating Origin (нет Z-fighting и дрожания float32).
- Все переходы камеры, FOV, экспозиции — через демпфированные пружины («Nothing Pops»).
- Базовый режим не требует внешних ассетов: текстуры, звуки, частицы — процедурные. Google 3D Tiles подключаются только по явной команде пользователя и API key.
- `npm run build` = строгая проверка TypeScript (`strict`) + сборка Vite.
